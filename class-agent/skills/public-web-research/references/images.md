# Image research

Assess whether the subject has meaningful visual material. Imagery is normally relevant for named
people, physical projects or products, places, artworks, interfaces, devices, and visually
distinguishable examples. It is normally unnecessary for forms, administrative answers, or abstract
topics where it would be decorative.

Prefer registered course assets. Otherwise search before the first composition open, using a short
natural-language query without `site:` filters or quoted syntax. Prefer figures, diagrams,
screenshots, prototypes, and official portraits from primary project or institutional sources. For
research projects, search the title plus a useful noun such as figure, diagram, prototype, or
interface. If no useful result appears, retry once with the distinctive title or name plus one visual
noun.

Inspect returned dimension and layout metadata before composing. When dimensions are known, preserve
them as `source_width` and `source_height`. Never use an unknown-dimension or small image as a banner
or feature. Use only returned verified HTTPS image URLs, with accurate alt text. Candidates are
evidence to inspect, not a basis for inferring identity or unsupported facts.

If candidates are uncertain, inspect up to four together before selecting the final visuals.
