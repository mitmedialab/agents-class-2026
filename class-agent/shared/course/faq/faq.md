## Week 1 assignment

### What does running a model locally mean for Week 1?

Use a downloaded LLM whose inference runs in Google Colab or on your computer. Hosted model APIs such as Anthropic or OpenAI do not satisfy the assignment. Implement the agent loop yourself without agent frameworks or SDKs such as the Claude Agent SDK. The application may be in any domain, but it must use an LLM-based agent loop; an image generator may be a tool or output, but cannot replace that loop.

## Newsletter highlights

### What criteria does the Course Agent use to choose the newsletter highlights?

Each week, the Course Agent reads what every student built on GitHub and put on their website. It looks at the week's folder, notes and commit messages in your repository (read-only), and at your post for the week on your project site. It scores each build from 0 to 10 on four criteria:

- **Originality (30%):** how unexpected and ambitious the idea is.
- **Assignment fit (25%):** whether it did what the week's assignment asked.
- **Cognitive augmentation (25%):** how directly it supports a cognitive outcome, such as helping a person think, remember, learn, focus, or decide while that person stays in charge.
- **Execution (20%):** whether it works and the website shows the build wholly.

Only what your repository and website show counts. A build needs at least 5 on assignment fit to rank ahead of the rest. Anyone featured in the last issue sits out that week. The four highest weighted scores are featured, and a tie goes to assignment fit, then originality.
