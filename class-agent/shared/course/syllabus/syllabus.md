# Sample Class Agent Syllabus

This is a development resource for the Class Agent platform. Replace it with the official course syllabus before deployment.

## Course format

The course explores extensible cognitive agents through readings, discussions, and student-built tools. Students should be able to inspect what the Course Agent knows, which capabilities it can use, and why those capabilities are authorized.

## Help
