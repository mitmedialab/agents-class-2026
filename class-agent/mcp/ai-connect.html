Choose your app

ChatGPT

  1. Open ChatGPT Plugins and add a custom MCP server.
  2. Paste the MCP server URL and select OAuth.
  3. Install it, sign in on the course website, and select the plugin in a new chat.
Open ChatGPT Plugins ↗

Claude

  1. In Claude, open Plugins or Customize → Connectors and add a custom remote connector.
  2. Paste the MCP server URL, sign in on the course website, and enable the connector in a chat.
Open Claude ↗

Gemini

  1. In Gemini, open Settings → Connected Apps → Add a custom app.
  2. Paste the MCP server URL and sign in on the course website.

Requires an eligible personal account and a callback configured by course staff.

Open Gemini ↗
